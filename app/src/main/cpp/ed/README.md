# Shared EdgeDrawing — app trial and evaluation

OpenCV contrib 4.12.0 `modules/ximgproc/src/edge_drawing.cpp`, associated headers and Apache-2.0 LICENSE are pinned from the verified Task3 source. Original license headers preserved. `precomp.hpp` adapts includes for the minimal existing-AAR bridge. The initial bridge differed only in its JNI class symbol. The subsequent ownership1 patch adds a test-only deterministic allocation audit and standard unique_ptr owners for ED buffers, NFA replacement, and partially allocated matrix rows. Original arithmetic and detector options are retained; source patch and original hashes are preserved outside the repository. Call-local Mat/Ptr and copied arrays remain. No gray-only/LUT/BSS source optimization.

Default EdgeDrawing parameters: PREWITT, Sigma1, NFAValidation=true, PFmode=false. Six-value ellipses have semiaxes (not diameters), degrees. The bridge does not apply gate/quality/truth/count/sample filters.

Install NDK r27d (27.3.13750724) using SDK Manager. Both custom tasks default to the project SDK’s `ndk/27.3.13750724` and reject other revisions. An optional `edgeDrawingNdk` Gradle property overrides the path (keep machine paths in user Gradle properties). Build with the pinned NDK: `./gradlew assembleDebug assembleRelease assembleDebugAndroidTest`; four API21 ABIs link only `libopencv_java4` from the existing org.opencv4.12.0 AAR. App JNI is generated in main for debug/release as libpounter_ed.so; androidTest builds the diagnostic libpounter_ed_test.so from the same calculation source. POUNTER_PRODUCTION removes fault injection/audit state and entry points. The app does not package evaluation fixtures or alternate selection policies. AAR's STL supplies libc++_shared. No native binary or private input is committed.

This is local evaluation, not distribution acceptance. Contrib source LICENSE retained; complete exact OpenCV/third-party/libc++ notice bundle must precede distribution. Static upstream LUT BSS remains; representative-device peak is Task7.

Ownership regression: the original source leaked NFA/LUT on normal replacement and Join scratch arrays after a later allocation failed (both reproduced with live delta2). The patched fixed ellipse fixture audits all1,641 reached owned allocation points plus retry, live delta0. This is deterministic injected allocation failure, not a real OS OOM/peak/leak profiler guarantee. Audit state is thread-local, enabled only for explicit JNI audit; normal detection cannot trigger injected failure. `ownership_test.hpp` uses standard unique_ptr deleters, no output/geometry policy changes.

## Even sampling correction (2026-10-16)

Evaluation version `edge-drawing-common-android-v2-even-sampling` reduces an ellipse validation request N to `N - N % 2` before sampling. The sampler already writes exactly `2 * floor(N/2)` paired coordinates. This retains every generated position and excludes the unwritten tail. Fixed real-photo10 JNI outputs remained unchanged; initialization correctness is distinct from accuracy. No AAR/contrib upgrade or product binding change.

From repository root, `python3 scripts/native_sampling_regression.py <outside-repo>/sampling.cpp` emits a standalone C++ regression from the actual sampler and caller branch. Optional `--source <before-source>` checks a preserved pre-fix source. Compile using the same NDK/AAR headers and `-Iapp/src/androidTest/cpp/ed`, link the existing AAR OpenCV, and run on the corresponding Android ABI with matching libc++/OpenCV libraries. Exit2 is missing/stale-generation failure; exit0 is coverage success. The source copy exposes private methods only for the test and marks paired y writes after x/y assignment; no numeric sentinel or unmarked coordinate is read. The fixture covers odd/even, grow/shrink, and actual circle sampling followed by ellipse fitting/buffer reuse, not the full automatic revalidation decision. Source-pattern changes fail generation instead of silently testing a separate sampler implementation. Full commands and RED/GREEN binaries are in this chat's external native-improvement-v1 evidence.
